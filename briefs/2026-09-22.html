Claude Code の開始時入力が 79K〜89K でばらつく理由を「要素を1つずつ外して復元」で分解した — MEMORY.md を空にすると −11,722、MCP 一式（道具名266種）を外すと −8,439、効果はほぼ足し算

— 起動の固定費（9/13特集）を自分の環境で測る手順そのもの。何を減らせば何トークン戻るかが、推測でなく数字で出る。

sumitsuke氏（9/20）。同じプロンプトで7セッションを回すと開始時の入力トークンが 86,159・86,613・88,756・89,509→79,440→85,765→88,045 と揺れた。測り方は ~/.claude/projects/<dir>/*.jsonl の最初の usage を input_tokens + cache_creation_input_tokens + cache_read_input_tokens で足す。cache_read が 0 のセッションは比較から捨てる。

切り分けは「1要素を外す→戻す」の繰り返し。MEMORY.md（15,340字・134行）をほぼ空にすると −11,722、MCP コネクタ一式（道具名266種＋指示文）を外すと −8,439、両方外した実測 53,925 は個別の差を足した期待値 54,072 と 147 しか違わず、要素の寄与はほぼ足し算で効く。含意: 「MEMORY.md を削る」「MCP を減らす」の効果は、その環境で一度測れば何トークン戻るかが先に分かる。hanafusay氏（9/19）の内訳も同じ測り方で自分の数字にできる。

試すなら: セッションを開いて同じ短いプロンプトを1回だけ送る → ~/.claude/projects/<dir>/<session>.jsonl の最初の assistant 行の usage を3項目足す → claude --strict-mcp-config --mcp-config '{"mcpServers":{}}' で MCP なし起動を同じ手順で測り、差を出す → MEMORY.md を退避して同様に測る。

出典: Qiita — Claude Code の開始時入力が 79K→88K に戻った——usage と、要素の除去→復元で「毎回入るもの」を分解する

Flutter の Widget Previewer をコマンドから撮って比べる CLI「shutter」— @Preview を PNG にし、2回分をピクセル差分で before／after にする（koji_1009氏、9/20）

— UI の変更確認を「見て判断」から「差分率と終了コード」に変えられる。AI に UI を直させる時の検収に置ける。

dart install shutter（Flutter 3.47 以上）。shutter shot lib/preview/button_preview.dart が @Preview 関数を PNG にし、shutter diff latest~1 latest --images が前回とのピクセル差分を出す。例ではボタン幅 66.69→98.69px で diff_ratio 0.4337。終了コードは diff が変更なし0／あり1。含意: hook や CI に置け、「差分があれば理由を報告」と書ける。

試すなら: dart install shutter → shutter doctor → shutter shot <プレビューのファイル>（プレビュー関数がなければ --widget 'PrimaryButton(label: "OK")' --import lib/ui/button.dart）を UI 変更の前後で2回 → shutter diff latest~1 latest --images で before／after の PNG を見る（pub.dev/packages/shutter v0.1.1、9/20 公開、koji-1009.com の検証済み publisher）。

出典: Zenn — Widget PreviewerをHuman/AI friendlyにするCLI shutter

MCP サーバーのツール定義は、繋いだだけでは全部読まれない — Datadog MCP は定義が 2万〜22万トークンでも Claude Code の増分は +1,097。名前と1行説明だけ先に載せ、引数の仕様は使う直前に読む（tool search）

— MCP を何本繋ぐかで「定義の大きさ」を恐れすぎなくてよい。ただし名前と1行の分は毎回積まれる（1件目の 8,439 はそれ）。

miyakeen氏（9/21）。Datadog MCP の定義は toolsets=core で約2万、all で 164,288、書き込み込み 218,183 トークン（curl＋tiktoken）。だが Claude Code に 36本（定義 23,415）を繋いだ実測の増分は +1,097。tool search（v2.1.221 以降は既定、ENABLE_TOOL_SEARCH=false で無効）が起動時は名前と短い説明だけ渡すため。含意: 起動の固定費は本数×（名前＋1行）、重いのはツールを使うターン。

試すなら: /mcp でサーバーごとのツール数を見る → 1件目の手順で MCP あり／なしの開始時 usage を比べて1本あたりの固定費を出す → 定義の大きいサーバーは toolsets=core のような絞り込みが README にあるか確認する（tool search の挙動と ENABLE_TOOL_SEARCH は docs/en/mcp で確認済み）。

出典: Zenn — Datadog MCP Serverのトークン消費を実測した ― 繋いだだけで2万、全部入りで22万
