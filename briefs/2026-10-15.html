OWASP ASVS の再点検を Claude Code の Skill に任せたら、全面点検 12 分 01 秒・$5.43 が「差分＋Bash あり」で 6 分 25 秒・$2.89（47% 減）。Bash を禁じると 4 分 21 秒まで縮むが退行を見逃し、依存コードを渡せば検出が戻る。--allowedTools は「それだけに制限」ではなく、Bash を止めるなら --disallowedTools Bash（suna 氏）

— claude -p＋Skill の無人点検を「何を渡して何を禁じるか」で設計した実測。--allowedTools の取り違えは自分の無人ジョブにもそのまま効く。

ゆきひろ氏（suna、10/14）。OWASP ASVS 5.0（Web アプリのセキュリティ要件集）の V7 セッション管理 18 要件を、第三者製 Skill agent-asvs と claude -p（Opus）で 4 条件点検。全面点検は 12 分 01 秒・$5.43・18/18 確認・Bash 34 回。差分（patch と stat、コミット一覧）を渡して Bash ありなら 6 分 25 秒・$2.89・17/18 で、前回見つけた退行も検出。API 換算コストは 47% 減。

Bash を禁じると 4 分 21 秒・$2.22・16/18 まで縮むが退行を見逃した。差分に依存コードを足すと 5 分 13 秒・$2.48・17/18 で検出が戻る。落とし穴が 2 つ。--allowedTools は「確認なしで実行してよい」の指定で、他のツールを使えなくする指定ではない（制限は --tools、除去は --disallowedTools）。渡した依存コードは package.json の 16.4.0 ではなく 16.2.4 で、Skill は気づかず処理した。含意: 無人点検は「渡す材料」と「禁じる道具」を別々に決め、禁じたら既知の退行 1 件で見逃しを確かめる。n=1、API 換算。

試すなら: git clone https://github.com/TarkinLarson/asvs-auditor /tmp/asvs-auditor && git -C /tmp/asvs-auditor checkout b426297 で中身を読んでから skills/agent-asvs を .claude/skills/ に置く → 差分を git diff <base> HEAD と git log --oneline <base>..HEAD でファイルに出して Skill に渡す → claude -p "agent-asvs で ASVS 5.0 の V7 を L2 まで点検。確認していない要件は『未チェック』と列挙" --allowedTools Read Grep Glob Skill --disallowedTools Bash --output-format json → 読み取りだけで足りない要件があれば依存コードのパスも渡し、版が合っているかを先に見る（--allowedTools＝確認なしで実行、--tools＝使えるツールの制限、--disallowedTools の裸のツール名＝文脈から除去、は docs/en/cli-reference）。

出典: Zenn — OWASP ASVS の再点検を AI Skill で効率化できるか — 4 回の実験で分かったこと

— 9/30 既報「司令塔」・10/12 既報 waiteu 氏のハブ分けを、公式が機能にした形。CLI では使えず、段階的ロールアウト。

プロジェクト＝司令塔の会話＋スレッド。スレッドは独立した文脈窓を持つクラウドセッションで、自分のブランチで作業し PR を開いて報告だけ返す。持つのはプロジェクトの指示・メモリと各リポジトリの CLAUDE.md・skills。手元の設定は引き継がない。既定はスレッド Opus・high、司令塔 Opus・low。「2 本まで」「開始前に提案」はメモリに保存されるが上限ではない（強制は 1 日 200 スレッド）。1 時間以上寝たスレッドへの追加は全文を読み直すので新規が安い。GitHub.com 前提。

試すなら: claude.ai/code の左サイドバーに Projects が出ていれば New project → 名前だけで作成 → Project settings > General で Thread model／effort を下げる → 最初は小さな実タスクを 1 件送り、返ってきた PR とスレッドの報告の形を見る → 出ていなければ claude.com/form/projects で待機リストに（手順・既定値・200 スレッド／日・キャッシュ寿命の注意は docs/en/claude-projects）。
