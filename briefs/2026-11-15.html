空気清浄機と刺繍ミシンで、AI が公式アプリの通信を読み解いた 2 本が、今週の Hacker News で 776 点と 734 点。手で数日かかる所が約 20 分だった。実機が要るので、まだ試していない

Mac の Chrome を使わずに、Claude がページを開ける。ブラウザは Cloudflare の上

Cloudflare の Kitesurf（8 月に発表、11/13 にソースを公開。Browser Run では無料のベータ）。公開の試用口に CDP でつなぎ、このテックブリーフを開いた。文も一覧も読めたが、絵の中の日本語は □ になった

いま
1Claude がページを開くたび、Mac の上でブラウザが立ち上がる窓が前に出ると、打っていたキーがそちらに吸われることがある
2クラウドで動く Claude や Workers には、ふつうブラウザが無いCloudflare の Browser Run も、既定のブラウザは Chromium
Kitesurf だと
3ブラウザは Cloudflare の上。Claude は糸（CDP）を引くだけPuppeteer や Chrome DevTools MCP など、Chrome 向けの道具がそのままつながる
4メモリは Chromium の約 1/5。その代わり時間は 1.8 倍かかるCloudflare の説明書の表（14 の URL・5 回の中央値）。時間は 1,148 ms 対 637 ms
  • 中身は Rust の部品（HTML と配置の Blitz、CSS の Stylo、JavaScript の Boa）を WebAssembly にしたもの。Chromium の入れ物は使わない
  • 使い方は 2 つ。Cloudflare の Browser Run で browser=kitesurf を付ける（無料のベータ、アカウントごとの上限あり）か、ソースから自分の Workers に置く（Workers の有料プランが要る）

Claude が本物の筆で絵を描き、気に入らない一筆だけを自分で直せる

Klad（11/12 に Show HN、v0.2.0）。画像生成ではなく、一筆ずつがデータで残る描画アプリ。Rust でビルドする形なので、まだ試していない

いま
1画像生成だと、葉っぱ 1 枚が気に入らなくても、描き直しは全体のくじ引き
2座標を書かせる方式は、一部を直すにもコードを読むことになるこのテックブリーフの絵も、Claude が SVG の座標を書いている
Klad だと
3Claude はコマンドで、あなたはペンで、同じ絵に描く相手の一筆はすぐ見える。筆・レイヤー・タイムラインはどちらも同じものを使う
4気に入らない一筆だけ選んで、色・太さ・形を直す。付箋で Claude に頼むこともできるClaude の一筆には印が付き、どの変更も共通の履歴の 1 歩なので戻せる
  • Klad の中に画像のモデルは無い。何を描くかは Claude（や Codex）が決め、Klad は筆・レイヤー・タイムラインを渡す
  • README の作例（生き物・夜の場面・道具 12 個）は Claude Fable 5.2 が一筆ずつ描いたもの。描く順に再生して見られる
