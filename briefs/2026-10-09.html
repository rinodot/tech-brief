Pro の 5 時間枠を長持ちさせる分担 — メインの Opus 5.5 は計画と diff レビューだけ、実装は Sonnet、調査と commit／push は Haiku 5.5 のサブエージェントに回したら、PR 1 本あたり $3.59→$2.14（約 40% 減）、5 時間枠の消費は 1 本あたり約 10%→約 6%。効いたのは Sonnet の安さより「メインセッションの文脈を小さく保つ」こと（平均 75→54 リクエスト、119k→107k トークン）

— 10/3 既報の「effort の固定」（agents/*.md に model＋effort）と 10/7 既報の Agent ツールの effort を、使用枠の視点で測った実例。1 PR あたりの枠消費を自分のログで数える手順つき。

Andrea Grandi 氏（10/7、Pro）。.claude/agents/ に 4 体。implementer は model: sonnet・effort: medium、scoper は model: haiku・permissionMode: plan・maxTurns: 12、shipper は model: haiku・effort: low・maxTurns: 10、reviewer は opus で頼まれたときだけ。settings.json は "model": "opus" と effort medium、CLAUDE.md に「サブエージェントを使うのは常設の依頼」の 1 行。

結果は Opus のみ 24 PR の $3.59／本に対し 13 PR で $2.14／本、5 時間枠の消費は約 10%→約 6%／本（1 枠で約 10 本→約 16 本の見込み）。メインの平均は 75→54 リクエスト、119k→107k トークン。著者の見立ては、単価差ではなく実装のループを子に逃がしてメインの文脈が膨らまないこと。含意: 計画と承認だけをメインに残す分担は、費用より「同じ枠で何本やれるか」で効く。n=1、PR の規模（248→392 行）が違う、金額は API 換算。

試すなら: .claude/agents/implementer.md の frontmatter に model: sonnet と effort: medium、scoper.md に model: haiku・permissionMode: plan・maxTurns: 12 を書く（キーは docs/en/sub-agents の表で確認。maxTurns に達すると partial で返り、再開できる）→ CLAUDE.md に「実装と調査はサブエージェントに任せる。頼まれるのを待たない」を 1 行 → 1 PR ごとに /usage の 5 時間枠の前後差を控え、1 本あたりの % を 10 本ほど並べて前と比べる（数字と構成は記事）。

Google（10/7、public preview）。Firebase・Google Cloud・Android・Maps の公式ドキュメントを検索・全文取得・回答生成する Developer Knowledge API と、その MCP サーバー・gcloud コマンド・エージェントスキルが同時に出た。ツールは検索・全文・回答の 3 つ、認証は API キーをヘッダーで渡す。含意: Firebase の実装は書く前に公式を引かせる手が 1 行で入る。公開・英語のみ、Flutter／Dart の収録は明記なし、料金の記載なし。

Claude Code v2.1.294〜295（10/8）で使えるようになったこと — command／HTTP フックに onFailure: "block"（起動できない・タイムアウト・想定外の終了コードなら通さず止める）、Stop の prompt 型フックを指示文で書いたときの判定を改善（早く止まりにくく）、claude -p が最終ターン後に何を待っているかを stderr に 1 行、tool search 経由の MCP ツール説明が 2,048→16,384 字

— 10/8 既報の prompt 型 Stop フックの差し戻し率と、9/9 既報の「止まった hook は非ブロック」の両方に当たる変更。修正多数の中から運用に効くものだけ。

v2.1.294 は prompt／agent フックを指示文で書くと通してしまう件と、Stop の prompt フックの判定を直した 2 件。v2.1.295 は command／HTTP フックに onFailure: "block" が付き、起動できない・タイムアウト・想定外の終了コードのとき、既定の「通す」でなく「止める」を選べる。ほかに claude -p が何を待っているかを stderr に出す、tool search 経由の MCP ツール説明は 16,384 字まで。含意: 守りのフックを fail-closed にできる。

試すなら: claude update で 2.1.295 に → 秘密情報や危険コマンドを止める PreToolUse の command フックに "onFailure": "block" を足し、わざと exit 3 で終わらせて止まるか確かめる → Stop の prompt フックの文面は指示文でなく判定文（「次の場合だけ ok=false: …」）に揃え、10/8 既報の差し戻し率を 1 週間数え直す（変更点は github.com/anthropics/claude-code/releases の v2.1.294・v2.1.295 本文。onFailure の docs 記載は未確認）。
