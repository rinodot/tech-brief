Claude Code v2.1.314（10/30）: 作業ディレクトリの外への Write／Edit を全権限モードで拒否する permissions.blockWritesOutsideWorkingDirectories が入った。claude -p の起動失敗は「終了コード 0・無出力」から「エラー表示・終了コード 1」に、Monitor ツールのシェルコマンドにも Bash 向けフックが効くように

— 10/19 の読み取り側 blockReadsOutsideWorkingDirectories と対になる書き込み側。無人運転の「成功と誤認する穴」も 1 つ塞がった。

permissions.blockWritesOutsideWorkingDirectories: true で Write・Edit・NotebookEdit が作業ディレクトリの外を全権限モードで拒否する。Bash 経由の書き込みは対象外なので deny かサンドボックスと併用。ほかに claude -p が起動に失敗すると終了コード 1 でエラーを出す（従来は 0 で無出力＝成功扱いの穴）、Monitor のシェルコマンドにも Bash 向けフックが走る（止める・尋ねるのみ）。含意: 無人運転の守りが設定 1 行で増える。

試すなら: ~/.claude/settings.json の permissions に "blockWritesOutsideWorkingDirectories": true と "blockReadsOutsideWorkingDirectories": true を並べる → 無人スクリプトは claude -p の終了コード 1 を失敗として扱う分岐があるか確認 → Monitor 向けに書いた Bash(tail *) 系の hook if 条件が意図せず一致しないか見直す。
