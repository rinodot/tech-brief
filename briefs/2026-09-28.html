— 9/22 の「起動固定費の分解」と昨日の棚卸しの続き。測り方が claude -p の usage 1行で済み、今日から自分の CLAUDE.md で比べられる。

yuu_inaka氏（9/25）。「ok とだけ返してください」の1往復を claude -p --output-format json の usage で測ると入力 125,424 トークン、うち 96,472（77%）が CLAUDE.md。中身は消さず退避する: 毎回効く規律だけ残し、日付つきの出来事は docs/lessons/（月別）、手順書は docs/reference/、タスク固有の指示は .claude/agents/ のサブエージェント定義へ。先頭には「何がどこにあるか」の表と grep -rn "<語>" docs/lessons/ docs/reference/ の1行だけ置く。

結果、CLAUDE.md は 132,180 字→5,782 字、同じ1往復は 128,003→34,973 トークン（73%減）。サブエージェントを6人（定義の合計 22,671 字）足しても常時の文脈は +2,579 トークン。再肥大化は日次の検査で見張る（12,000 字超で警告）。含意: トークン減は費用減ではない。サブエージェントは既定で親のモデルを継ぐので、model: を書かないと Opus のまま動く。

試すなら: CLAUDE.md がある場所とない場所で claude -p "ok とだけ返してください" --output-format json | jq '.usage | (.input_tokens + .cache_creation_input_tokens + .cache_read_input_tokens)' を比べる → 差が大きければ「毎回効く規律」以外を docs/ と .claude/agents/ に移し、先頭に索引表と grep の1行を置く → 移した先を読む役には model: sonnet を付ける（測り方・退避先・数字は記事本文、--output-format json に usage と total_cost_usd が入ることは docs/en/headless で確認済み）。

Google の Antigravity SDK（Python のエージェント構築ライブラリ）がローカルモデルで動く — LocalOpenAIAgentConfig に Ollama の http://localhost:11434/v1 を渡すだけ。16GB の Mac で gemma4:12b が起動 1.9 秒・ファイル作成タスク 16.7 秒、メモリ 8.1GB

— Android Studio にも入った Antigravity のエージェントを、手元の GPU と Ollama で回せる。クラウド課金なしの試作に。

公式 docs と amu_lab氏の検証（9/25）。LiteRTAgentConfig は Gemma 4 26B A4B 専用でメモリ 24GB 以上推奨、LocalOpenAIAgentConfig は Ollama／LM Studio／vLLM に繋ぐのでモデルは自由。amu_lab氏は M5 16GB で gemma4:12b（実メモリ 8.1GB）を動かし、起動 1.9 秒、「hello.txt を作って DONE」が 16.7 秒、空きメモリ 10%。含意: 12〜16GB なら 12B 級を Ollama 経由で、26B は載らない。

試すなら: pip install google-antigravity litert-lm → ollama pull gemma4:12b → LocalOpenAIAgentConfig(model="gemma4:12b", base_url="http://localhost:11434/v1").lightweight() を Agent(config) に渡す → policy.allow_all() は試作だけにする（クラス名・URL・24GB の推奨・CUDA と Metal の自動検出は antigravity.google/docs/sdk/local-models で確認済み。数字は記事本文）。
