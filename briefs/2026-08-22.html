Claude Code v2.1.239 — あなたの使う4つの仕組み全部に修正が入った

— サブエージェント常用なら、長時間セッションのメモリ増大修正がそのまま効く。

8/21公開のv2.1.239は60項目超の大きめの回で、CLAUDE.md・Skills・Hooks・サブエージェント・MCPの全系統に修正が入った。効きが大きいのはサブエージェント周りで、長いセッションでサブエージェントのツール結果が解放されずメモリが際限なく膨らむ問題が直り、表示範囲を出た時点で解放されるようになった。Hooksでは、PreToolUseフックで遅延した実行が別トレース扱いになりOpenTelemetry（実行の記録を追う仕組み）の記録が分断される問題と、作業ディレクトリを消したあとフックが起動失敗する問題を修正。Skillsは.mdがBOM（ファイル先頭の不可視マーカー）付きだと黙って無視される問題、MCPは一時的なサーバーエラー後に再接続しても失敗表示のままになる問題が直った。

課金絡みも1件ある。プロキシ経由でBedrockを使うとストリーミングが壊れ、毎ターン非ストリーミングで再実行されてAPI課金が黙って倍になっていた不具合が直った（サブスク利用なら無関係）。含意: 週末のうちに更新しておくと、来週のサブエージェント運用が軽くなる。

出典: Claude Code changelog

Anthropicが無料の学習サイト「Claude Academy」を開講 — 日本語alpha付き

— 自分のCLAUDE.md/Skills運用を公式の型と突き合わせる材料。週末向き。

Anthropicが社内で使っている新人向けAI教育カリキュラムを、academy.claude.comで一般公開した。Claude CodeとCowork中心の講座に加え、法務・セキュリティなど職種別の学習経路、人間とエージェントの分業を扱う教材、「4D AIフルーエンシー」という習熟フレームが並ぶ。日本語訳はalpha版で、進捗はアカウントに記録される。含意: 自己流で組んだCLAUDE.mdやSkillsの型を、公式の標準と突き合わせる機会になる。無料なので週末に一周する価値はある。

出典: Anthropic

公式が「スタートアップ向けClaude Code運用ガイド」を公開 — 今週の拾い漏らし

— CLAUDE.md・Hooks・サブエージェントの置き方が名指しで書かれた、今週いちばん実務に近い文書。

8/20公開ぶんで、昨日までの号で拾えていなかった。中身はあなたの構成そのもので、アーキテクチャの非交渉ルールはリポジトリ直下のCLAUDE.mdに置く、全社共通手順は共有Skillsディレクトリに置く、lint/テストと秘密情報の除去はHooksで固定点に挿す、レビューや分析はサブエージェントを並列で当てる、と具体的だ。長丁場の自律作業には停止条件つきの反復「Loops」を、作り直しの検証にはgit worktreeを充てる。含意: 自分の運用設計を照合するチェックリストとして読める。

出典: Anthropic

今週のまとめ

大きかったのは8/20のGA発表で、Skills API・Files API・Computer Useが正式版になった。SkillsはClaudeのサンドボックス内で動くため別途ホスティングが不要、Filesは組織あたり1TB・レート上限5倍。ローカルLLMではQwen3.8-27Bの量子化品質が論争中で、Unslothの「同サイズ比10%改善」に対し第三者が自前の3bit版で上回ったと報告した（測定条件がバラバラで、まだ決着していない）。週次上限50%増は8/31まで再延長されたまま。GitHubは8/17障害の原因分析を公開し、CPU300万コア増設とAzure比率58%への引き上げを表明した。Debianのライセンス投票は8/28締切。
