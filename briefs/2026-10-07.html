Claude Code v2.1.290〜292（10/5〜10/6）で使えるようになったこと — サブエージェント呼び出しに effort を指定、WebSearch の回数制限が「200 回で終わり」から「1 時間に 100 回ずつ回復」に、WebFetch は 10 万字を超えたら未読分を伝えて offset で続きを読める、claude plugin install に --marketplace

— 10/3 既報の「effort は agents/*.md に固定」の続き。修正中心の 3 本から、運用に効く変更だけ拾った。

Agent ツールに effort が付き、呼び出しごとに low／high を指定できる（これまでは agents/*.md か親の継承）。WebSearch は 200 回で打ち止めから 1 時間 100 回の回復式に（CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR）。claude attach <名前> で背景セッションに名前で入れる。/code-review の medium が cleanup と CLAUDE.md 規約の指摘も出す。含意: effort の使い分けが設定ファイルでなく依頼文で書ける。

試すなら: claude update で 2.1.292 に → サブエージェントへの依頼に「effort は low で」と添え、/usage で前後を比べる → 長いページは WebFetch の結果に未読量が出たら offset で続きを頼む → プラグインは claude plugin install <plugin> --marketplace <source> の 1 行で登録と導入をまとめる（いずれも github.com/anthropics/claude-code/releases の v2.1.290〜292 本文で確認。docs への反映は未確認）。
