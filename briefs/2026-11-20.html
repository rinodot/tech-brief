21 回ずつ許可を押す守り方は、遅いうえに、そのうち読まずに押すようになる記事:「ひどい働き方だ。遅くていらいらし、すぐに判断疲れになる」
external sandbox を使うと
3Claude は Mac にいたまま、コマンドだけを箱に渡す箱に見えるのは渡したフォルダだけ。ネットは最初から切れている
4外へは許した行き先だけ。本物の鍵は門番が箱の外で付ける箱の中にあるのは使い捨ての札だけ。返事に鍵が混ざって戻ってきても、伏せ字になって箱へ届いた（試して確かめた）
  • 記事:「箱は、どのモデルの判断にも頼らない守り」。Claude Code の auto mode のような AI の見張りとは別の層、という位置づけ

  • 今回試したのは v86 版（npm の 1 パッケージ・約 36MB で、Linux の中身ごと入っている）。npx で取ってきて動かすだけで、sudo も Mac への設定の追加も要らない

試した: このサイトの写しで、Claude Code（Opus 5.5）を箱につないだ

ターミナル 2 つ
1# 1 つ目: 箱を立てる（6.1 秒で起動）
2npx external-sandbox-v86@0.4.0 \
3 --preserve-paths --mount-rw "project=$PWD"

5CLAUDE_CODE_SHELL_PREFIX=…/claude-shell-prefix-http.sh \
6CLAUDE_CODE_TMPDIR="$PWD/.external-sandbox-claude-tmp" \

8EXTERNAL_SANDBOX_API_URL=http://127.0.0.1:8686 \

Claude に 4 つ頼んだ結果（6 手・18.5 秒）

Claude 自身の報告:「Bash は別の隔離された環境で動いているようです」
  • 箱の中から見ると、ユーザーは agent、HOME は空、/Users/rinodot も ~/.ssh も「No such file」。環境変数は 10 個で、token・key・secret を含む名前は 0 個
  • Claude は Bash で一覧を作り直す Python も動かせた（箱に Python 3.12・git・ripgrep がある。Node は無い）
  • 私の設定（hooks・MCP）を読ませないよう --setting-sources project --strict-mcp-config で動かした。ふだんの設定のままだと、hooks・ステータス行・MCP の起動コマンドも箱の中で動く（README の注意）

速さ: このサイトの一覧を作り直す Python で比べた

Claude が、録音した音を 1 つも使わずに楽器を「計算」で鳴らし、曲まで作る。子どもの動画に自前の BGM

きしだ氏の記事（11/13、はてブ 205）を、Fable 5.2 で本人の動画づくりに当てた。標準ライブラリだけの 557 行で、30 秒のピアノとオルゴールの曲ができた（私は音を聞けないので、数字で確かめた）

1いま: 祖父母に送る絵本動画は、子どもの声だけkid-voice-video の手順と道具に、BGM を入れる処理は無い
2Fable 5.2 は、ハンマー・弦・響板の動きを 1 サンプルずつ計算して音にするフェルトのばね・弦を行き来する波・響板の 48 の揺れ方（作ったコードの説明）。音源ファイルは使わない
3曲も作った: 4 小節 + 4 小節。7 小節目から遅くなり、オルゴールの余韻で終わる和音は F–Dm–B♭–C、F/A–B♭–Gm7·C7–F（Fable の説明。遅くなる所はコードで確かめた）
4私の案: 声の下に小さく流す。曲はコードから何度でも同じに作り直せるまだ動画には入れていない。聞いて決めるのは本人
  • きしだ氏は Fable 5.2 に弦楽器・ピアノ・金管・木管・ギター・歌声の物理モデルを作らせ、作曲もさせた。「指示してないのにソナタ形式になって、転調とかもちゃんとしてました」「ピアノはかなり出来がいいです」
  • 同じ頼み方の Opus 5.5 版は「まず物理音源のピアノがしょぼい」「曲も構成がやっぱ単純」（同じ記事）。記事のデモはブラウザで鳴る
