Claude Code v2.1.251 — モデル切替にフックを挟めるようになった

— フック・費用・権限の3方向に手が入った回。運用設計を作り込むほど効く。

フックではPreModelSwitchとPostModelSwitchが新設され、モデルの切り替えをブロックしたり確認を挟んだり注釈を付けたりできるようになった。SessionStartのresumeフックは、セッションの鮮度と再キャッシュの推定費用を受け取れる。費用側は/costにセッション単位のプロンプトキャッシュ行が付き、ヒット率・ミス数・再キャッシュしたトークン数・warm/coldが見える。/usageには支出上限のバーが加わった。権限まわりの修正が重い。許可の判定を通ったあとにシンボリックリンクを差し替えられるTOCTOU（判定と使用の間に対象がすり替わる穴）とプラグイン配布元でのパストラバーサルを塞ぎ、サンドボックスの隔離を弱める管理設定には承認を要求するようにした。

Opus 5でeffortをxhigh／maxにしつつthinkingを切るとエラーになる不具合も直り、/effortはモデルごとに既定値を覚えるようになった。含意: フックを挟める場所が増えるほど、フック自体が停止要因にもなる。前版で直った「大量のエラーでセッションが固まる」件と併せて見ておきたい。

出典: Claude Code changelog

AIが自動生成した権利侵害申立でLuantiがGoogle Playから消えた

— 人が確認しない申立で、ある日ストアから消えうるという実例。

オープンソースのゲーム基盤Luanti（旧Minetest）がGoogle Playから削除された。理由はMicrosoftの代理を務めるTracer.AIからのDMCA通知で、「Minecraft Java Edition 1.9の登録資産を侵害している」と主張するが、どの資産がどう侵害しているかの説明も証拠もない。Tracer.AIは自社サイトで、AIによる自動検出で「従来比85%速い削除」「審査6倍速」を掲げる。反論通知は提出済みだが未復旧だ。含意: 配布経路を1本に頑らない理由がまた1つ増えた。

出典: Luanti公式ブログ

Debianの投票は延長されていなかった — 締切は予定どおり通過

— 昨日「裏が取れない」と書いた件の決着。報道のほうが取り違えていた。

締切は当初どおり8/28 23:59 UTCで通過した。Project Secretaryが8/26に出した最終投票呼びかけも、8/27と8/28の返信も、締切を8/28のままとしている。独立した6ソースも投票期間を8/15〜8/28と記載する。延長されたのは投票ではなく、その前の討論期間（7/23開始・8/13終了）のほうで、報道はここを取り違えた可能性が高い。締切時点の集計は投票487件・有効366件・投票者357人。含意: 結果は数日以内に出る。

出典: Debian 集計ページ
