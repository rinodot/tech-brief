Claude の長い説明を、付箋のホワイトボードで寄り道しながら読む。本筋の会話は汚れない

understand-mode（/understand スキル・11/13 公開）。審査で止めたので入れていない。芯の「会話を写して横で答えさせる」だけを、素の Claude Code で試した

1分からない所を本筋で聞くと、寄り道が本筋の会話に積もる本筋の Claude は、そのあとも寄り道ごと抱えて進む
2文を選ぶと付箋が生え、本筋の会話を写した分身がその中で答える付箋の中で続けて聞ける。答えの文を選ぶと子の付箋。図（Mermaid）やグラフも描く
3終わったら、本筋に効く付箋だけを 1 通にまとめて返す残りの付箋と分身の会話の記録は消える
  • 付箋ごとに claude -p --resume <本筋> --fork-session を走らせ、思考量（effort）は low。分身はファイルを読めるが、編集とコマンドは禁止。本筋のセッションには触れない、と README にある
  • 組み込みの /btw も「会話に残さない横の質問」だが、道具は使えず、1 問ずつの答え（公式ドキュメント）。付箋はそれぞれ続きが聞け、枝分かれでき、最後に本筋へ返せるところが違う

試した: 本筋の会話を写して 2 問聞いたあと、本筋の記録は変わったか

同じ2 問聞いたあと
  • 本筋は 1 件目の Quint の試しのセッション（記録 557 行）。understand-mode と同じ頼み方（「もう一段詳しく」「この用語を」）を、--fork-session・effort low・編集とコマンドは禁止で 2 回。2 問目は 1 問目の分岐からさらに分岐した
  • 前後で、本筋の記録の指紋（sha256）・行数・更新時刻は同じだった
  • 分身は本筋を引き継ぎ、seed や行番号まで挙げて答えた。ただし「二重タップでも join が 2 本走りうる」と書いたのは誤り（1 件目のとおり、同じ端末ではアプリの旗が弾く）。分身の答えも、そのままは信じない

Claude が一度うまくやった仕事を、手元のローカル LLM でもできるように教え込む。先生役の Claude が 3 回ずつ試させて直す

skill-distill（11/21 公開）。教えるループ本体はまだ回していない。生徒役（Claude Code の土台に手元の qwen3:30b）は、小さな仕事を 110 秒でこなした

1Claude がうまくやった仕事を、手元のモデルにも任せたい同じ頼み方だけで同じ出来になるかは、試さないと分からない
2先生役の Claude が、うまくいった会話を読み返し、生徒向けの手順書を書く答えそのものは書かない決まり。手順・判断の理由・落とし穴・確かめ方を書く
3生徒を 3 回ずつ走らせ、見本と比べて「最初にずれた所」を直す3 回とも見本どおりになるまで繰り返す。8 版まで、または 3 版続けて伸びなければ止めて報告
4最後は人が並べて見て合否を決める。合格した手順書で、手元のモデルが同じ仕事をする手順書は「どのモデル・どの土台・どの仕事」に 1 つずつ
  • 手順書（SKILL.md）には試運転の失敗が書いてある: 生徒 3 回とも機能はそろい、縮小図では見本と同じに見えたので先生役は 8.5〜9 点を付けたが、使う人に「出来が全然違う」と即座に落とされた。それで「等倍で並べて見る」「見た目にも数字の物差しを渡す」が決まりになっている
  • 生徒の土台は omp（oh-my-pi）・Codex・Claude Code・pi・opencode の 5 つ。README で「試した」とあるのは omp だけ。Claude Code は「書いたが未検証」

試した: Claude Code の土台に、手元の qwen3:30b をつないで生徒にできるか

1 回で
  • 手順書の最初の確かめ（「hello.txt に hi と書いて DONE と返して」で、生徒が動くかを 1 分で見る）を、Claude Code の生徒で行った。この Mac（メモリ 48GB）・Ollama 0.34.4 の Anthropic 互換の窓口・qwen3:30b。結果は 2 往復・110 秒で、hello.txt の中身は hi だった
  • 入力のほとんどは Claude Code が毎回付ける指示文。生徒の 1 回はこの分だけ重い。手順書は 3 回 × 何版も走らせるので、一晩がかりになりそう（私の見立て。ループは回していない）
  • 本人の設定は読ませていない（--setting-sources project --strict-mcp-config、使える道具は Write と Read だけ）。終わって Ollama は止めた

気をつけること

生徒は全権限・本人の設定のまま走るClaude Code 用の adapters/claude.sh は --dangerously-skip-permissions で、hooks や MCP を切る指定が無い。試すなら設定を切る指定を足す
できて 1 日11/21 公開、コミット 2 つ、Star 257（11/22 3 時）。README が指す examples/ はまだ無い
ローカルの生徒は遅い小さな仕事 1 回で 110 秒。合格まで何版かかるかは、仕事しだい
