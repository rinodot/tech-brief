いろいろな利用者になりきった Claude が、自分のアプリを触って、つまずいた所を写真つきで返してくる

mobile-agent-testers（11/19 v0.1.0・MIT）は、20 台のスマホでこれを同時にやる。道具は安全審査で止めたので、芯だけをパワログで試した。2 人で計約 5 分、2 人とも目標を果たし、文字を最大にすると画面の下が切れるのを見つけた

1いま: 自分のスマホ 1 台、いつもの文字の大きさで確かめる文字を最大にしている人や、片手で急ぐ人の画面は見ていない
2入れると: 20 台のスマホに 1 人ずつ、別の人を演じる Claude小さな iPhone・スウェーデン語・文字最大、Android・文字 200%、アラビア語（右から左）など 20 人が用意済み。台本は書かない
3つまずいた所が、画面の写真と再現の手順つきで返る重さ（止まる・困る・気になる）つき。同じ原因の報告は、手元の Claude が 1 つにまとめる
  • 道具は iOS シミュレータと Android エミュレータを GitHub Actions の上で動かし、各台の Claude Code に「画面を見る・押す・打つ」の道具を渡す。Flutter はそのまま組み立てられる（README）
  • 公開リポジトリなら Actions は無料で、払うのはモデルの分だけ（README の実例で 1 台 $0.15〜0.55）。Claude の定額プランなら使用量に数えられる
